1. SOURCE CLASSROOM STATUS NOT UPDATING
   ==================================================

CURRENT BUG:

Example:

* User changes Classroom 3 Flooring:
  Yet to start -> In Progress

* Popup appears:
  Apply to:

  * Classroom 1
  * Classroom 2
  * All classrooms

When user selects Classroom 1:

* Classroom 1 gets updated correctly
* BUT Classroom 3 itself DOES NOT update

THIS IS WRONG.

REQUIRED FIX:

The source classroom (the classroom where user initiated the change)
MUST ALWAYS update first.

Then apply duplication to selected classrooms.

CORRECT FLOW:

Example:
Classroom 3 Flooring:
Yet to start -> In Progress

User selects:
Apply to Classroom 1

RESULT SHOULD BE:
✅ Classroom 3 -> In Progress
✅ Classroom 1 -> In Progress

NOT:
❌ Classroom 3 unchanged
✅ Classroom 1 updated

BACKEND FIX:

Ensure bulk update API:

1. always includes source classroom
2. updates source classroom first
3. then updates selected classrooms

Frontend:

* optimistic UI should update source room immediately
* prevent stale local state overwrite

VALIDATE:

* only current classroom
* selected classrooms
* all classrooms

Refresh page and verify DB persistence.
