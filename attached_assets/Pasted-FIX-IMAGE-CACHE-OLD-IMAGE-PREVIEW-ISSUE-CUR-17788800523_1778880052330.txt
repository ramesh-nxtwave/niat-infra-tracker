==================================================
ROOT CAUSE
==========

Current image URL probably remains unchanged.

Example:
same object URL reused repeatedly

Browser caches old image aggressively.

==================================================
REQUIRED FIX
============

Implement cache busting for image previews.

==================================================
OPTION 1 — RECOMMENDED
======================

Always generate UNIQUE image URLs.

Example:
Instead of overwriting existing image:
uploads/university-1/checklist-1/latest.jpg

Generate:
uploads/university-1/checklist-1/uuid-timestamp.jpg

Example:
uploads/89742a08-2570-4936-9bca-d1646861bdab-1747331221.jpg

This is the BEST solution.

==================================================
OPTION 2 — CACHE BUST QUERY PARAM
=================================

Append timestamp/version to image preview.

Example:

```js
const imageUrl = `${photoUrl}?t=${updatedAt}`;
```

OR:

```js
const imageUrl = `${photoUrl}?v=${Date.now()}`;
```

This forces browser refresh.
