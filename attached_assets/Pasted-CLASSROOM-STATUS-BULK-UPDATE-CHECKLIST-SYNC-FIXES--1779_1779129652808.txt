2. BULK DUPLICATION / APPLY TO MULTIPLE CLASSROOMS
==================================================

Current pain point:
APMs manually update the same checklist item for many classrooms.

Example:
Classrooms:

* 201
* 202
* 203
* 204

Checklist item:
“Flooring”

Updating one-by-one is extremely time consuming.

Required feature:
When user updates a checklist item, show a duplication/apply popup.

Example:
Classroom 202
Flooring:
Yet to Start → In Progress

System should ask:

“Do you want to apply this update to other classrooms?”

Options:

* Only this classroom
* Apply to selected classrooms
* Apply to all classrooms

If selected:

* update same checklist item across chosen classrooms
* copy:

  * status
  * remarks
  * timelines
  * blocker state
  * completion date
  * confidence info if applicable

DO NOT overwrite unrelated checklist items.

Important logic:
If Classroom 203 already has:
Flooring = Done

and user updates Classroom 202:
Flooring = In Progress

then:

* ask before overwriting completed data
* optionally skip completed classrooms

Suggested UX:
Modal popup with:
☑ Classroom 201
☑ Classroom 202
☑ Classroom 204

Buttons:

* Apply
* Cancel

4. CLASSROOM RENAME BREAKING CHECKLIST LINK
===========================================

Current issue:
When classroom name changes:
“Classroom 101” → “Classroom 1”

Checklist disappears and shows:
“No checklist items found for this room.”

Root cause:
Checklist linkage is likely based on room name instead of stable room ID.

Required fix:
Checklist must always be linked using:

* classroom UUID / room ID
  NOT room name.

When classroom name changes:

* existing checklist statuses should remain
* evidence should remain
* history should remain
* timelines should remain

Do NOT recreate checklist items unnecessarily.

Expected behavior:
Rename:
Classroom 101 → Classroom 1

Result:

* same classroom
* same checklist
* same evidence
* only display name updated
