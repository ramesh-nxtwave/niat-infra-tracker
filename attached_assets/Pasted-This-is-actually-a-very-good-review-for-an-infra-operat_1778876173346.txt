CRITICAL ISSUE — FILE STORAGE
=============================

Current issue:
Uploaded images are stored on local filesystem.

Problem:
Replit deployments are ephemeral.
Any restart/redeployment can wipe uploaded files.

This is NOT acceptable for production.

==================================================
REQUIRED SOLUTION
=================

Keep entire platform inside Replit ecosystem.

Use:
Replit Object Storage / Replit Buckets

DO NOT use:

* local uploads folder for production
* filesystem persistence
* temporary storage

NEW FILE STORAGE ARCHITECTURE
=============================

Implement:

1. Upload file to Replit Object Storage

3. Store URL in PostgreSQL

* object_key

* uploaded_at
